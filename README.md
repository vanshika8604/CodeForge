# CodeForge

A real-time collaborative coding platform inspired by VS Code and LeetCode.

## Features

- 🔐 JWT Authentication
- 👨‍💻 Real-time Collaborative Code Editor
- ⚡ Code Execution
- 🤖 AI Code Review
- 💬 Live Chat
- 🚀 Dockerized Backend
- 🗄 PostgreSQL + Prisma
- 🌐 REST API
- 🔌 Socket.IO
- 📄 Monaco Editor

## Tech Stack

### Backend
- Node.js
- Express
- TypeScript
- PostgreSQL
- Prisma
- JWT
- Docker
- Socket.IO

### Frontend
- React
- TypeScript
- Tailwind CSS
- Monaco Editor

- OpenAI API
